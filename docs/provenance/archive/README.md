# Archived decoder development records

This directory preserves a small, selected record of the decoder's planning
and early implementation. The documents originated in the parent Radiogram
project before GramPy was extracted into a separate repository.

The files are retained verbatim as historical evidence. They are not current
requirements, normative protocol documentation, or instructions for
maintaining GramPy. Their technical details and repository-relative references
may be outdated. Current decoder documentation is under `docs/decoder/`.

The selection is intentionally narrow:

- the initial specification-first decoder roadmap;
- the design and implementation specifications that separated wire behavior
  from receiver architecture; and
- the first three implementation-session records, covering the initial
  package, controlled fixtures, and first complete NumPy IQ-to-text slice.

The source copies were under `history/docs/` in the parent repository. The
SHA-256 hashes recorded in the top-level `PROVENANCE.md` identify both those
source copies and the byte-identical files preserved here. The parent
repository and its commit history may provide additional corroboration, but
neither is required to build or use GramPy.
